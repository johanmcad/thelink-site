Compatibility

Works with.

Link works with equipment that has a modern 3.5 mm RS‑232 control jack with a selectable baud rate. It detects the model automatically — there is no picker — and adapts the remote to that model’s inputs and features.

All listed models share the published control protocol; the C2700 is the reference unit. Detection is automatic, so a model that is not on this list but speaks the same protocol is still recognised and controlled with a generic input layout.

Also on the same Link

The rest of the rack.

Bowers & Wilkins DB1

Up to two DB1 subwoofers on their own ports. Gain, presets, mute and the full settings page.

McIntosh MEN220

Room correction mode — bypass, global or a measured position — and voicing.

Eversolo streamers

Now playing with cover art and transport controls over the network. Other UPnP/DLNA players: transport only.

Not supported

Only one-way connections.

Equipment with only a Data Port, an IR input or trigger outputs — for example the C2200, C2300, MA7000 and MA252. Those connections cannot report state, and Link never guesses. Link does not use infrared in any form.

If a receiver or processor has a volume scale setting, leave it on the linear 0–99 scale.
